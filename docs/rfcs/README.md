# RFCs and open questions

These RFCs contain implementation proposals with open questions. When a proposal
is resolved, its decision moves into [an ADR](../adr/README.md) and the RFC is
removed, or marked `resolved` while other records still link to it.

| RFC                                               | Topic                             | Status |
| ------------------------------------------------- | --------------------------------- | ------ |
| [0001](0001-optional-hooks-and-automation.md)     | Optional hooks and automation     | draft  |
| [0002](0002-adoption-and-tool-ownership.md)       | Adoption and tool ownership       | draft  |
| [0003](0003-retiring-the-standards-repository.md) | Retiring the standards repository | draft  |

Start with the [installation guide](../installation.md) and
[current standards](../conventions/README.md) for implemented behavior. Hooks
can follow after manual use is useful. RFC-0002 discusses gradual adoption, and
RFC-0003 tracks what still has to move out of the predecessor repository.
