# RFCs and open questions

These RFCs contain implementation proposals and their resolutions. Drafts are
open questions; resolved RFCs link to their owning decision and implementation.
Accepted architectural direction lives in [the ADRs](../adr/README.md).

| RFC                                           | Topic                         | Status   |
| --------------------------------------------- | ----------------------------- | -------- |
| [0001](0001-contextual-project-updates.md)    | Contextual project updates    | resolved |
| [0002](0002-project-scoped-distribution.md)   | Project-scoped distribution   | resolved |
| [0003](0003-optional-hooks-and-automation.md) | Optional hooks and automation | draft    |
| [0004](0004-migration-and-ecosystem.md)       | Adoption and tool ownership   | draft    |
| [0005](0005-authoring-and-review.md)          | Authoring and review          | draft    |

Start with the [installation guide](../installation.md) and
[current standards](../conventions/README.md) for implemented behavior. Hooks
can follow after manual use is useful. RFC-0004 discusses gradual adoption;
RFC-0005 explores how instruction review can improve through project trials.
